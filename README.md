# Week 7 Assignment: Database Design and Normalization

## Overview
This assignment demonstrates database normalization using First Normal Form (1NF) and Second Normal Form (2NF) in MySQL.

## Learning Objectives
- Understand First Normal Form (1NF).
- Understand Second Normal Form (2NF).
- Eliminate repeating groups and partial dependencies.
- Create relational tables using primary keys and foreign keys.
- Improve database organization and data integrity.

## Questions Completed

### Question 1: First Normal Form (1NF)
Transformed the ProductDetail table so that each row contains only one product per order.

### Question 2: Second Normal Form (2NF)
Separated order information into Orders and OrderItems tables to eliminate the partial dependency of CustomerName on OrderID.
